# GranjaWeb

Este projeto é uma atividade da disciplina de Programação para Web I, em que consiste em praticar os conhecimentos adquiridos com o ReactJS.

## Tecnologias utilizadas

- ReactJS
- React Bootstrap
- React Router Dom
- React Icons

## Estrutura do projeto

```
GranjaWeb/
    ├── public/                  # Imagens, ícones e svg
    ├── src/
    |   ├── components/          # Componentes reutilizáveis da interface
    |   ├── layouts/             # Estrutura base das páginas
    |   ├── views/               # Páginas da aplicação
    |   ├── App.jsx              # Componente principal da aplicação onde contém as rotas
    |   └── main.jsx             # Inicializa a aplicação React
    └── index.html
```

## Como executar o projeto

1. No terminal, clone o repositório: ```git clone https://github.com/RhuanFelix/GranjaWeb.git```;

2. Abra o projeto no terminal ou na sua IDE de preferência;

    2.1. Caso tenha aberto pela IDE, abra o terminal da sua IDE e faça os seguintes passos no terminal;

3. Instale as dependências: ```npm install```;

4. Execute o projeto: ```npm run dev```.
